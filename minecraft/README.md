# Minecraft World Prototype

This directory contains a simple procedural Minecraft-inspired world generator with rockets.

## Files
- `minecraft_rocket_world.py` – generates a world file with grass, trees, lava, and rockets.

## Run
```bash
python minecraft_rocket_world.py
```

## Output
The script writes a text file named `rocket_world.txt` under the `minecraft` folder.

## Notes
This is a lightweight prototype and not an actual Minecraft Java world save file. It is intended for game-design experimentation and custom content generation workflows.
