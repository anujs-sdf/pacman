# Roblox Game Deployment Guide

## 1. Open Roblox Studio
- Launch Roblox Studio.
- Create a new Place.
- Choose a blank baseplate or a template you like.

## 2. Create the game script
- In the Explorer panel, find `ServerScriptService`.
- Insert a new `Script`.
- Copy the Lua code from `roblox.py` or paste the script directly from the Python file output.

## 3. Run the game
- Click the Play button in Roblox Studio.
- Test movement with WASD or arrow keys.
- Click the sword to damage enemies.

## 4. Publish the game
- In Roblox Studio, go to File > Publish to Roblox.
- Sign in to your Roblox account.
- Choose a place name and set the visibility.
- Publish the experience.

## 5. Share the game
- Open the Roblox Developer Hub or your Roblox profile.
- Copy the game link and share it with others.

## 6. Optional improvements
- Add sound effects.
- Add a boss fight.
- Add a start menu.
- Add coins, upgrades, and a leaderboard.

## Notes
- This is a simple prototype Roblox game.
- For production use, add better animations, UI, and balance tuning.
- Use DataStoreService if you want player progression saved long-term.
